# Design System

组织级设计系统资产。每个子目录是一套可复用的模版。

| 模版 | 说明 | 状态 |
|---|---|---|
| [micro-saas-template-products-xconnect-1.0](./micro-saas-template-products-xconnect-1.0/) | Micro SaaS 四页模版 v1.0（产品主页 / 用户中心 / 订阅计费 / 帮助中心），首个落地案例为 XConnect | ✅ v1.0 |

## 使用方式

1. 读 `DESIGN-SYSTEM.md` —— 规范、审计依据与分批迁移路径。
2. 浏览器打开 `00-design-overview.html` —— 四页平铺设计稿 + token 摘要。
3. `tokens.css` 可直接并入项目的全局样式，或按作用域引入。
